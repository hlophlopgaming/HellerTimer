# HellerTimer icon

The amber hourglass is formed by a looping ribbon: time and the circular paradox of Joseph Heller's *Catch-22*. The intertwined silhouette also hints at a pair of mirrored twos. This replaces the borrowed Pomatez icon.

Generated with the built-in image generation tool, then downsampled to a 256×256 PNG with alpha using Lanczos. Runtime/UI assets use this small PNG, not the large generation output. Copies are used for the desktop window, package icon, website, web manifest and Android launcher.

Exact generation prompt:

> Use case: logo-brand. Asset type: final desktop application icon for HellerTimer, a quiet native Pomodoro timer named after Joseph Heller, author of Catch-22. Create ONE polished square app icon, centered: a bold continuous ribbon forming an hourglass and a subtle impossible loop (the Catch-22 paradox), with an understated suggestion of two mirrored 2 shapes in its negative space. Refined geometric silhouette, legible at 24 pixels, wide substantial strokes, very few shapes. Warm amber and ivory ribbon on a deep midnight navy rounded square, tiny restrained cyan accent if needed. Flat graphic design, crisp edges, no tiny details, no lettering, no numbers, no text, no watermark, no drop shadow outside the tile, no mockup, no presentation board. The rounded square fills most of the image with a small transparent margin. This is an original mark, not Pomatez's tomato logo. Transparent canvas outside the rounded-square tile.
